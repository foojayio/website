**Foojay is run by a small team of Java community people, backed by a much larger group of contributors, authors and podcast guests who make the site what it is day to day. Here's who's steering the ship.**

{{< team-member name="Geertjan Wielenga" role="Founder of Foojay" image="/images/pages/meet-the-team/geertjan-3-41-32-120x120.png" >}}
Geertjan founded Foojay and is still the driving force behind it, staying deeply involved in the community he built. He's an open source and Java enthusiast, a Java Champion, an Apache Member, and leader of the Amsterdam Java User Group.
{{< /team-member >}}

{{< team-member name="Frank Delporte" role="Lead Reviewer, Editor & Contributor · Host of the Foojay Podcast" image="/images/pages/meet-the-team/cropped-frank-delporte-scaled-1-120x120.jpg" >}}
Frank is Foojay's main reviewer, editor, and contributor, and hosts the Foojay Podcast. He's a Java Champion, a Senior Technical Writer at Azul, and the author of *[Java Programming for Raspberry Pi — A Hands-On Guide to Electronics and IoT Projects](https://webtechie.be/books/)*. He writes and talks about Java in business production environments, but also in places people don't always expect it — on the Raspberry Pi, driving GPIO pins, rendering JavaFX UIs, and running on RISC-V single-board computers.

In 2026, Frank led the AI-assisted migration of Foojay from WordPress to a static [Hugo](https://gohugo.io/) site, making the authoring flow easier for contributors, integrating external data for Java User Groups and Java Champions more cleanly, and giving the site much faster loading, next to many other improvements. 
{{< /team-member >}}

{{< team-member name="Dominika Tasarz-Sochacka" role="Community, Editing, Maintenance & Sponsorships" image="/images/pages/meet-the-team/cropped-Dominika-2025-Speaker-Profile-Square-120x120.png" >}}
Dominika is the newest addition to the Foojay team, looking after community, editing, platform maintenance, and sponsorships, alongside contributing her own community content. She's a community builder focused on growing the global Java and Jakarta EE ecosystems, specializing in community strategy, open source engagement, and developer-focused technical marketing. She currently works as a Senior Developer Advocate at Azul, supporting community growth around Azul Payara Community and Jakarta EE.
{{< /team-member >}}
