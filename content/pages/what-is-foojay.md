Foojay.io, the website for **F**riends **O**f **O**pen**J**DK, is the integrated dashboard for all things Java: a central resource for daily information, curated highlights and categorized reference material for the Java community.

Rather than one single blog or one vendor's view, Foojay collates news, technical deep-dives, release data, podcasts, and community voices into one place. It's a free and vendor-neutral place for the Java community, owned and run by [Azul](https://www.azul.com/), which holds the FOOJAY trademark, hosts the site and funds the [small team](/meet-the-team/) behind it.

On Foojay, you can find the following content (and more!):

* **[Daily News](/today/)** - a daily stream of blog posts, tutorials and news from [Java developers, JDK engineers and industry contributors around the world](/today/author/).
* **[The Foojay Podcast](/today/category/podcast/)** - conversations with the people building and shaping the Java platform.
* **[OpenJDK Release Details](/java-almanac/)** - the Java Version Almanac: every JDK release with its docs, specs and API diffs, so you can see exactly what changed between two versions.
* **[Glossary](/java-terms-explained/) \& [Java Quick Start](/java-quick-start/)** - reference material and guided tutorials for developers learning Java or getting oriented in the ecosystem.
* **[JC-AI Newsletter](/today/category/jc-ai-newsletter/)** - a regular briefing at the intersection of Java and AI.
* **[Event Calendar](/calendar/)** - Java events happening worldwide.
* **[Java User Groups](/jugs/)** - a world map of the JUGs near you, sourced live from the community-run World Wide JUGs directory.
* **[Java Champions](/java-champions/)** - the community members recognized by the Java Champions program, sourced live from the official directory.

## Why we're here

Java developers shouldn't have to piece together useful information from many different sources. We wanted one place that's accurate, timely and vendor-neutral, where you can trust what you're reading because it comes from community members working on Java hands-on.

## How Foojay is funded and edited

Azul started the Foojay project in 2020 and the maintainers of the site work for Azul. [Sponsors](/our-sponsors/) add to that and get visibility in return: a profile page, a logo and homepage banners. They do not commission or approve articles, and a sponsor never decides what gets published.

Articles come from across the ecosystem, including from companies that compete with Azul. Each one is the opinion of its named author, not a position of Foojay, Azul or a sponsor. Paid banners are always marked "Sponsored Content".

## Join in

Foojay is made by its community, and there are three ways to take part:

* **Write for Foojay.** Send an article as a pull request on [GitHub](https://github.com/foojayio/website). [CONTRIBUTING.md](https://github.com/foojayio/website/blob/main/CONTRIBUTING.md) explains the format. A maintainer reviews it, and the automated checks catch the formatting problems. All the other pages also live on GitHub and you can improve them by createing a pull request.
* **Talk it through on [GitHub Discussions](https://github.com/foojayio/website/discussions)**, for ideas, questions and feedback on the site or an article.
* **Chat with us on [Slack](/today/join-slack-com-t-foojay-signup/).**

## Where the name comes from

"Foo" is the placeholder in demo apps, and Foojay is a placeholder for your content, "Foo" for "J", as in Java. "Jay" is also a bird, which gave us the logo. Oracle owns the trademark on Java and OpenJDK and doesn't allow initiatives like ours to use those names freely, so "Foojay" became the place for **F**riends **O**f **O**pen**J**DK.
