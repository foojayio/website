Digma is the first Continuous Feedback (CF) platform for developers. Developers use Digma to code faster in distributed, complex or legacy systems with faster feedback loops. Our platform integrates into the code and IDE to enable developers to find runtime issues earlier in the dev cycle, decipher complex code behavior and rapidly validate code changes.
When we started Digma, we made a decision to create a product from the trenches. A product with the domain language of code, that evolves from opinionated code analysis that can only come from a community developers. Digma is free for developers because we rely on the community for its feedback and expertise that makes its way into the product. We picked Java as Digma’s first and primary supported coding language because of the strength and maturity of the Java community, its champions community and tooling.
