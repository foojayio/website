In this myth-busting webinar, Steve Millidge (founder of [Payara](https://www.payara.fish/)), shows you that Java/Jakarta EE **IS** Cloud-native and can handle microservices and containers in the Cloud.

In this webinar, learn:

* What is Cloud-Native?
* How [Jakarta EE](https://jakarta.ee/) (Java EE) applications run securely in the Cloud
* Why you should build applications, not runtimes
* How to keep your runtime easily up-to-date
* Learn about an upcoming project,**[Payara Cloud](https://www.payara.fish/products/payara-cloud/)**, that separates the deployment from the runtime to make running Jakarta EE applications on the cloud even easier

If you've been hearing that Java/Jakarta EE is not Cloud-native or it's difficult to get your Java/Jakarta EE applications running in the Cloud, watch this webinar to see why that's not true and how you can continue using your existing Java/Jakarta EE development skills to modernize your application development!
