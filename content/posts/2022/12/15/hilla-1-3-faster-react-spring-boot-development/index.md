Hilla is a full-stack web framework for Spring Boot.

With its type-safe server communication, building apps is faster (autocomplete everywhere) and refactoring them is safer (compile time errors vs production).

Hilla includes 45+ UI components and integrated build tooling so you can get a full-stack project running in a minute.

Hilla 1.3 adds support for using React to build the frontend.

**Release highlights**

* New: [React support](https://hilla.dev/docs/react) (including React wrappers for all Vaadin components)
* New: [Hilla CLI](https://www.npmjs.com/package/@hilla/cli)
