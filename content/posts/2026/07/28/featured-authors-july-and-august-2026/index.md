Foojay wouldn't exist without the many contributions from its community, whether it's a single post or an ongoing stream of knowledge sharing. That's why we've started highlighting two of them each month as **[Featured Authors](https://foojay.io/today/author/)**. We kicked this off in July with Igor and Steve, and this post covers both our July and August (Cristobal and Shai) featured authors. Want to read more from any of them? Just click their name to visit their Foojay author page, where you'll find their full list of posts. We'll be back with the next update at the beginning of September.

## July 2026

**[Igor De Souza](https://foojay.io/today/author/igor-de-souza/)** writes for beginners and the wider Java community, blending accessible teaching with pop-culture hooks and hardware projects. His recent posts include a Quarkus Pi4J extension for Raspberry Pi development, a myth-busting piece using a Star Wars framing to argue Java is easier to learn than reputed, a fact-based look at whether Java "really" uses too much memory (tying JEPs to real memory improvements), and pieces marking Pokémon's and Zelda's anniversaries as vehicles to explain Java's evolution (compact source files, flexible constructors, performance gains). He's also behind the new Java in Education catalog and appears on Foojay podcasts about STEM outreach and making Java approachable for students and newcomers. Overall his writing is playful, education-focused, and aimed at demystifying Java for beginners while highlighting community and IoT projects.

**[Steve Poole](https://foojay.io/today/author/steve-poole/)** writes almost entirely about Java security and software supply chain risk, with a sharp, analytical, often provocative voice. Recent posts cover AI-assisted vulnerability discovery outpacing patching ("AI Found the Bugs, Who's Patching Your EOL Java Code?"), a wave of new Jackson CVEs found via AI-assisted research, a broader argument that AI may be permanently breaking the economics of software security, Spring Boot's migration pressures under the EU Cyber Resilience Act, developers over-trusting AI dependency suggestions, and a two-part deep dive on Grails' revival and its EOL/Spring Boot entanglements. He also appears on Foojay podcasts discussing Java app security and podcasting itself. His work targets experienced Java/Spring practitioners and decision-makers, focused on the collision of AI, security research, and legal/regulatory compliance (CRA).

## August 2026

**[Cristobal Escobar](https://foojay.io/today/author/cristobal-escobar/)** writes almost exclusively about BoxLang, the modern dynamic JVM language he develops and promotes. His recent posts trace the language's active release cadence in detail: new features in the 1.14.0 and 1.15.0 lines (dynamic Sets, lazy typed Ranges, inner/template classes, query transformers, JSONPath support in DataNavigator, a faster BoxStringBuilder), infrastructure pieces like a new AWS/Azure/Google Secrets Manager module, and BoxLang AI updates (image generation, web search, agent registry, MCP observability). The tone is hands-on and release-notes-driven, aimed at developers who want to track what's new in BoxLang and how to use it in real applications, including cloud, DevOps, and AI-adjacent use cases.

**[Shai Almog](https://foojay.io/today/author/shai-almog/)** covers a broader mix of Java-adjacent topics, but his most recent posts focus on Codename One, the cross-platform Java framework, with weekly-style updates on iOS Metal rendering, a new Build Cloud console, native theme work (Material 3, Liquid Glass), device APIs, and developer tooling like AI-agent skills for generated projects. Further back in his archive he's also known for practical debugging deep-dives (front-end debugging, strace, console.log tricks) and Java API extension techniques. Overall his writing blends framework release updates with tutorial-style, tools-and-techniques content for working developers.
