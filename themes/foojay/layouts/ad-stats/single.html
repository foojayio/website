How these are counted

An impression is a banner that was at least half on screen for a full second, in a tab in the foreground, counted once per campaign per page load. A click is a press of the banner's own call-to-action button; the optional second button, which links to a foojay page rather than to the advertiser, is not counted.

The counter stores a key and an integer — no cookie, no identifier, no third-party script — so these are indicative totals rather than audited ad-server figures. Readers with JavaScript disabled are not counted at all, which means the true impression count is a little higher than the one shown.
