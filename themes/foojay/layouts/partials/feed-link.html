{{- /* A VISIBLE "subscribe by RSS" link -- the single definition of how a feed is offered to a reader, so the home page, /today/, a category, /pedia/, /calendar/ and a sponsor profile cannot each invent their own wording, icon or placement. Every one of those pages has had a feed all along and advertised it only as a in -- which a browser stopped showing a button for years ago, so in practice the feeds existed and nobody could find them. The one exception was a category page, which had a "Subscribe via RSS" ghost button; that wording and this partial are now the same thing. Context (.) is either the page whose feed to link, or a dict: page the page whose `rss` output format to link (required) label the visible text, default "RSS feed" Renders NOTHING when that page has no rss output, so a caller never has to guard -- and a page that loses its feed loses the link with it rather than shipping a dead one. Note the page passed in need not be the page being rendered: /ai/ is a portal over one category, so it links THAT term's feed, the same way it links the term page itself. The icon is inline SVG rather than a font glyph or an : it is one shape, it inherits its size from the text, and it must not be a network request on 4000 pages. It is `aria-hidden`, with the visible label carrying the accessible name -- an icon-only feed link is the thing this partial exists to stop. */ -}} {{- $page := . -}} {{- $label := "RSS feed" -}} {{- if reflect.IsMap . -}} {{- $page = .page -}} {{- with .label }}{{ $label = . }}{{ end -}} {{- end -}} {{- with $page.OutputFormats.Get "rss" -}} {{- /* Material's RSS mark: the dot plus two arcs, at 24x24. */ -}} {{ $label }} {{- end -}}
