{{- /* A VISIBLE "subscribe by RSS" link -- the single definition of how a feed is offered, so the home page, /today/, a category, /pedia/, /calendar/ and a sponsor profile cannot each invent their own wording, icon or placement. A in is not an offer: browsers stopped showing a button for it years ago. Context (.) is the page whose `rss` output format to link, or a dict with `page` set to it -- for a caller linking a feed other than its own. /ai/ is a portal over one category, so it links THAT term's feed. THE LABEL IS NOT A PARAMETER. It was, and one caller promptly said "Machine Learning RSS feed" while every other said "RSS feed", so the same control read as a different control. Renders NOTHING when the page has no rss output, so a caller never has to guard and a page that loses its feed loses the link with it. IT OPENS IN A NEW TAB, against the usual same-origin rule, because the destination is not a page: browsers show a wall of raw XML or hand it to a reader app, so in the same tab a curious click costs the reader their place. The sponsorship PDF is linked the same way. `noopener` is written out although browsers imply it, matching the other new-tab links. The icon is inline SVG -- one shape, inheriting its size from the text, and not a network request on 4000 pages. `aria-hidden`, with the visible label carrying the accessible name: an icon-only feed link is what this partial exists to stop. */ -}} {{- $page := . -}} {{- if reflect.IsMap . }}{{ $page = .page }}{{ end -}} {{- with $page.OutputFormats.Get "rss" -}} {{- /* Material's RSS mark: the dot plus two arcs, at 24x24. */ -}} RSS feed {{- end -}}
