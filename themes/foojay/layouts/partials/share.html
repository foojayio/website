{{- /* "Share this page", at the foot of an article, beside page-source.html. PLAIN LINKS TO SHARE INTENTS, not a third-party widget: a widget is a tracker, a network request on 4,000 pages and a layout shift, and an works with JavaScript off and is keyboard-reachable for free. THE NETWORKS ARE FOOJAY'S OWN (menu.footer -> footer-social) plus the two aggregators a Java audience actually posts to. No Twitter/X: the footer dropped it, and offering a network foojay is not on is odd. Three controls need JavaScript and are therefore rendered `hidden` and unhidden by static/js/share.js -- in place, so the row keeps one order whether or not the script runs. Mastodon is one of them because its share URL is per-instance: there is no host to put in an href until the reader names theirs. data-pagefind-ignore for page-source.html's reason: one row on 4,000 pages otherwise makes every one of them a result for "Bluesky". Every href is built whole and passed through safeURL. Go escapes an interpolation that lands after a `?` in an href, so an already-encoded value dropped in there comes out double-encoded (%20 -> %2520). */ -}} {{- $url := .Permalink -}} {{- $title := .Title -}} {{- /* The page's OWN description, not meta-description.html: that one falls back to the site boilerplate for a page without one, and "foojay.io is the place for Friends Of OpenJDK" under every share post is noise. */ -}} {{- $desc := "" -}} {{- with .Params.description }}{{ $desc = plainify . }}{{ end -}} {{- $names := partial "author-names.html" . -}} {{- /* Capped at two named plus a count: a post can credit a dozen people, and the credit is competing with the description for the same 300. */ -}} {{- $credit := "" -}} {{- if $names -}} {{- if gt (len $names) 3 -}} {{- $credit = printf "Posted by %s and %d others on foojay.io" (delimit (first 2 $names) ", ") (sub (len $names) 2) -}} {{- else -}} {{- $credit = printf "Posted by %s on foojay.io" (delimit $names ", " " and ") -}} {{- end -}} {{- end -}} {{- /* ONE sentence, cut to each channel's own limit by share-text.html -- Bluesky counts 300 graphemes and Mastodon 500, and a post that arrives in the composer already over the limit is one the reader has to edit before they can send it. 0 is "no limit". */ -}} {{- $args := dict "title" $title "desc" $desc "credit" $credit "url" $url -}} {{- $bsky := partial "share-text.html" (merge $args (dict "limit" 300)) -}} {{- $masto := partial "share-text.html" (merge $args (dict "limit" 500)) -}} {{- /* The email subject and the OS share sheet both carry the title on their own, so neither of these repeats it. The sheet is handed the URL as its own field, which is why the summary stops before it. */ -}} {{- $lines := slice -}} {{- with $desc }}{{ $lines = $lines | append . }}{{ end -}} {{- with $credit }}{{ $lines = $lines | append . }}{{ end -}} {{- $summary := delimit $lines "\n\n" -}} {{- $body := delimit ($lines | append $url) "\n\n" -}} {{- /* Reddit's own title field, and it caps at 300. */ -}} {{- $redditTitle := truncate 300 "…" $title -}} {{- /* urlquery writes a space as `+`, which a mail client shows literally in a mailto body (RFC 6068 is percent-encoding only). %20 is correct in every one of these, so they all get the same treatment rather than the mailto one being the odd link out. */ -}} {{- $qUrl := replace (urlquery $url) "+" "%20" -}} {{- $qTitle := replace (urlquery $redditTitle) "+" "%20" -}} {{- $qBsky := replace (urlquery $bsky) "+" "%20" -}} {{- $qSubject := replace (urlquery $title) "+" "%20" -}} {{- $qBody := replace (urlquery $body) "+" "%20" -}}
