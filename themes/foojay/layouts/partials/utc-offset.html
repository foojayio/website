{{- /* A time's UTC offset, written so a reader can act on it: "UTC+2", "UTC-5", "UTC+5:30", or plain "UTC" at zero. Takes a Time, returns a string. Used by calendar-events.html, only on the days that need it. DERIVED FROM THE TIME, not a table of zone names: a time parsed from a numeric offset carries no zone NAME, so Go's "MST" layout prints "-0500" where "CDT" is wanted. Arithmetic needs no table, cannot go stale, and handles the half- and three-quarter-hour offsets (India, Nepal, Chatham) a naive "UTC+N" would round away. */ -}} {{- $raw := .Format "-0700" -}} {{- $sign := substr $raw 0 1 -}} {{- $h := int (substr $raw 1 2) -}} {{- $m := int (substr $raw 3 2) -}} {{- $out := "UTC" -}} {{- if or (gt $h 0) (gt $m 0) -}} {{- $out = printf "UTC%s%d" $sign $h -}} {{- if gt $m 0 }}{{ $out = printf "%s:%02d" $out $m }}{{ end -}} {{- end -}} {{- return $out -}}
