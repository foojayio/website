DERIVED FROM THE FILE, like the transcript: a comments.json in the bundle means a section here, and a post without one renders nothing. No frontmatter flag to set, forget or unset. WHY THE ARCHIVE IS HTML AND IS PRINTED WITH safeHTML. hugo.toml sets goldmark `unsafe = true` for post bodies, so running comment bodies written by strangers through `markdownify` would be a stored-XSS hole. The sanitizing therefore happened ONCE, at import, with jsoup's Safelist, and what is stored is already safe. Two consequences: - `safeHTML` here is correct ONLY because of that. Never point this partial at unsanitized comment HTML, and never hand-edit a comments.json to add markup the safelist would have dropped. - Nothing else is escaped by hand: author and date go through Hugo's normal escaping, so a name containing `<` is text, not markup. AN ORDINARY SECTION, NOT A COLLAPSED
: find-in-page does not look inside a closed one, so Ctrl-F for a commenter's name would miss the one page that says it. data-pagefind-ignore, as with the transcript: 25,000 words of comments against a 113,000-word index would make a post a hit for any aside left under it and bury the archive people search for. EVERY COMMENT IS BOUND TO A VARIABLE ($c) rather than read off the dot. Inside a partial `$` is the PAGE passed in, not the ranged item, so a `{{ with .authorUrl }}` block reaching for `$.author` silently resolves against the page's params and prints nothing. */ -}} {{- $comments := "" -}} {{- with .Resources.GetMatch "comments.json" -}} {{- $comments = . | transform.Unmarshal -}} {{- end -}} {{- with $comments -}}
