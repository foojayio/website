{{- /* "Thanks to our sponsors" sidebar widget, driven by content/sponsors/ -- the same bundles behind /our-sponsors/ and each profile. ROWS PER TIER, not one row per sponsor: as a vertical list this was ~420px of a sticky column that also carries a TOC and a banner, so the lower tiers sat below the fold -- the opposite of what a sponsor pays for. Grouped, every tier is visible at once in half the height. Tier sets both the ORDER (gold, silver, bronze, alphabetical within) and the SIZE, so the placement reflects what each tier pays for. There is no per-sponsor name caption: the row says the tier once, and the logo's alt carries the sponsor's name, so the link keeps its accessible name. Order comes from sponsors-ordered.html, which also guarantees that a sponsor on a tier missing from `tiers` is appended rather than dropped. Unlike the authors/JUGs widgets this is NOT dropped on pages with a TOC: sponsor visibility is contractual. */ -}} {{- $section := site.GetPage "/sponsors" -}} {{- with $section -}} {{- $ordered := partial "sponsors-ordered.html" . -}} {{- with $ordered }} {{- $known := slice -}} {{- range $section.Params.tiers }}{{ $known = $known | append .name }}{{ end -}}
