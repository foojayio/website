{{- /* The single definition of a page's meta description -- baseof.html uses it for and og:description, json-ld.html for the BlogPosting/Person description, so the three cannot disagree. Author profiles and category terms carry no description of their own, so without the derivations below ~470 URLs would share one boilerplate string. They are DERIVED rather than asked for: an author already writes a `bio:`, and a term page knows its own name and how many articles it holds. Order: an explicit description always wins, then the derivation for the kinds that have one, then the site string as a last resort. */ -}} {{- $desc := "" -}} {{- with .Params.description }}{{ $desc = . }}{{ end -}} {{- if not $desc -}} {{- if eq .Type "author" -}} {{/* 332 of 344 authors have a bio. The remaining 12 get their name and what the page actually is, which still beats the site boilerplate. */}} {{- with .Params.bio -}} {{- $desc = . -}} {{- else -}} {{- $desc = printf "Articles by %s on foojay.io, the place for Friends Of OpenJDK." .Title -}} {{- end -}} {{- else if eq .Type "sponsor" -}} {{/* Most sponsor bundles carry `description: ""`, so the pages with money attached were the ones describing themselves with site boilerplate. Derived from what the profile knows; a bundle with its own description still wins. */}} {{- $n := len (partial "sponsor-posts.html" .) -}} {{- $desc = printf "%s sponsors foojay.io, the place for Friends Of OpenJDK. Read their %d article%s and meet the team behind them." .Title $n (cond (eq $n 1) "" "s") -}} {{- else if eq .Kind "term" -}} {{- $n := len .Pages -}} {{- $desc = printf "%d article%s about %s, written by the Java community on foojay.io — the place for Friends Of OpenJDK." $n (cond (eq $n 1) "" "s") .Title -}} {{- end -}} {{- end -}} {{- if not $desc }}{{ $desc = site.Params.description }}{{ end -}} {{- /* One length guard for every source, because none is reliably short: hundreds of imported descriptions run past 160 characters, and a bio is written for the profile rather than for a search result. Nothing past ~200 characters is rendered by an engine or a link preview, so `truncate` cuts on a WORD boundary rather than letting Google cut mid-word. The stored text is untouched -- this only shapes the tag. */ -}} {{- return (plainify $desc | truncate 200 "…") -}}
