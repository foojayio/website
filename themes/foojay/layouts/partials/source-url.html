{{- /* THE GITHUB URL FOR A PAGE'S OWN SOURCE FILE -- one definition of that URL's shape, used by page-source.html for "Edit this page" and by posts/single.html for the "suggest a correction" link on a transcript, which points at a DIFFERENT file in the same bundle. That second caller is why this is a URL builder and not just the link partial. Everything is derived from .File.Path, so there is nothing per page to write and no way for a link to point at a file that is not the one being read. Returns "" in every case where a link would be wrong, so a caller can `with` the result: .File is nil on a page Hugo GENERATES rather than reads, and an unset [params.source] means a fork has no business advertising an edit button into foojay's repository. Call with a Page for its own file, or (dict "page" $ "file" "transcript.md") for a sibling inside its bundle. */ -}} {{- $page := . -}} {{- $file := "" -}} {{- if reflect.IsMap . -}} {{- $page = .page -}} {{- $file = .file | default "" -}} {{- end -}} {{- $url := "" -}} {{- with site.Params.source -}} {{- $repo := strings.TrimSuffix "/" (.repo | default "") -}} {{- $branch := .branch | default "main" -}} {{- with $page.File -}} {{- $path := .Path -}} {{- /* path.Dir rather than .File.Dir: one call, no trailing-slash semantics to remember, and it is the same value either way. */ -}} {{- with $file -}}{{- $path = path.Join (path.Dir $page.File.Path) . -}}{{- end -}} {{- with $repo -}}{{- $url = printf "%s/edit/%s/content/%s" . $branch $path -}}{{- end -}} {{- end -}} {{- end -}} {{- return $url -}}
