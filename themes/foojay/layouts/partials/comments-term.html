{{- /* The giscus discussion term for a page, or "" if the page has no comment section. Takes the page. ONE definition, because two templates must agree and the failure is silent either way: comments.html renders the section, and toc.html offers the "Join the discussion" jump link. A condition and the thing it guards belong in the same place. WHICH SECTIONS: a list below, same shape as views-key.html's $counted. `.Type eq .Section` is what keeps this honest about the `pages` section, DERIVED rather than a blocklist. content/pages/ holds two kinds of thing: pages whose FILE is the page, rendered by _default/single.html, which calls comments.html; and pages carrying only an intro while a layout derives the rest, routed by `type:`, which do not. Testing the `type:` that already does the routing means a new derived page excludes itself, with no list to remember. The named exclusions on top are editorial: legal text is not a conversation, and /sitemap/, /search/ and /ai-instructions/ are machinery. THE TERM SHAPE DIFFERS BY SECTION, DELIBERATELY. A post keeps the BARE slug it has always had -- hugo.toml's mapping and every thread already created agree on it, and changing it would orphan all of them. Every other section is `
/`, because a bare slug is not unique across sections: content/pedia/records.md and a post slugged "records" would share one discussion. views-key.html qualifies its key for the same reason. */ -}} {{- $discussable := slice "posts" "pedia" "pages" -}} {{- $never := slice "privacy-policy" "terms-of-use" "accessibility" "sitemap" "search" "ai-instructions" -}} {{- $term := "" -}} {{- /* Config first: on a fork or an unconfigured build giscus renders nothing, so there is no anchor and there must be no link to one either. */ -}} {{- with site.Params.giscus -}} {{- if and .repo .repoId .category .categoryId -}} {{- with $ -}} {{- /* `.File` for the same reason views-key.html needs it: the slug comes from the file name, so a generated page has nothing to key on. `.IsPage` keeps a section LISTING out. */ -}} {{- if and .File .IsPage (in $discussable .Section) (eq .Type .Section) -}} {{- $slug := or .Params.slug .File.ContentBaseName -}} {{- if not (in $never $slug) -}} {{- $term = cond (eq .Section "posts") $slug (printf "%s/%s" .Section $slug) -}} {{- end -}} {{- end -}} {{- end -}} {{- end -}} {{- end -}} {{- return $term -}}
