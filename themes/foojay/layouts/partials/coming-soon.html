{{/* "Coming Soon" -- posts written and scheduled but not yet published. WHY THIS READS THE FILESYSTEM INSTEAD OF RANGING OVER PAGES. `buildFuture` is false, so a post with a future `date:` is skipped ENTIRELY -- no page, and no entry in site.Pages, any list, term, feed, sitemap or the Pagefind index. That is exactly what scheduling wants, but it means no template can `range` for these, so they are read as DATA, off disk. Turning `buildFuture` on instead would put them back in reach at the price of a `where .Date "lt" now` in every list, term, feed and JSON-LD template plus the Pagefind body -- and ONE missed spot publishes an embargoed article early, silently. Nothing here is authored: scheduling is a future `date:` and the usual folder. No `scheduled:` flag to set, and none to forget to unset. COMPARISON IS BY DAY, NOT INSTANT. Every post goes out at the one daily build, so a scheduled post is dated `YYYY-MM-DD` with no time and checkPostDates rejects one that carries a time. Day granularity is also Hugo's own rule -- a date-only post is midnight UTC -- so the two cannot drift into a post listed neither here nor on the site. Only this month and the next three are scanned, day folders from today onwards: ~4 directory listings, not a walk of 2000 posts. A post further out is not shown, and not lost -- it publishes off its own date. */}} {{ $today := now.UTC.Format "2006-01-02" }} {{ $scheduled := slice }} {{/* Anchored to the FIRST of the month before adding months: Go's AddDate normalises overflow, so "31 August" + 1 month is 1 October and September would never be scanned at all. */}} {{ $monthStart := time.AsTime (printf "%s-01T00:00:00Z" (now.UTC.Format "2006-01")) }} {{ range $i := seq 0 3 }} {{ $month := $monthStart.AddDate 0 $i 0 }} {{ $monthDir := printf "content/posts/%s" ($month.Format "2006/01") }} {{ if fileExists $monthDir }} {{ range $day := os.ReadDir $monthDir }} {{ if $day.IsDir }} {{ $folderDate := printf "%s-%s" ($month.Format "2006-01") $day.Name }} {{/* ISO dates compare correctly as strings. Anything unrecognisable is left out quietly and reported by checkPostDates. */}} {{ $date := substr (printf "%v" (.date | default "")) 0 10 }} {{ if and (findRE `^\d{4}-\d{2}-\d{2}$` $date) (gt $date $today) }} {{ $scheduled = $scheduled | append (dict "title" (.title | default $bundle.Name) "date" $date "authors" (.authors | default slice)) }} {{ end }} {{ end }} {{ end }} {{ end }} {{ end }} {{ end }} {{ end }} {{ end }} {{ end }} {{/* Renders NOTHING when nothing is scheduled -- the normal state, and an empty "Coming soon" heading is worse than no section.
