{{- /* The pager control, rendered above AND below a paginated grid. Replaces `_internal/pagination.html`, whose nested spans and anchor-marked current page could not be styled consistently from the outside. Every cell here is ONE element with one class (`pagination__btn`), so arrows, numbers, the current page and the disabled ends are the same box by construction. Non-links are ``, so keyboard focus only lands somewhere you can actually go. The ends are NUMBERED rather than "««"/"»»": a button reading 215 both jumps to the last page and says how many there are, which is why there is no "Page 3 of 215" caption. The « and » arrows are pinned to the row's outer edges so they stay under the cursor while paging. Called as `partial "pagination.html" (dict "page" . "position" "top")`; `position` only picks the spacing modifier. The pager comes from partials/paginator.html -- see there for why .Paginate is never called directly. */ -}} {{- $page := .page | default . -}} {{- $position := .position | default "bottom" -}} {{/* Optional `anchor`: an element id appended to every pager link, so the browser lands back at the list rather than the top of the document. Needed where the grid sits below a bio and stats; omitted on /today/ and the category pages, where the grid is already the top of the content. */}} {{- $anchor := "" -}} {{- with .anchor }}{{ $anchor = printf "#%s" . }}{{ end -}} {{- $pager := partial "paginator.html" $page -}} {{- with $pager -}} {{- if gt .TotalPages 1 -}} {{- $cur := .PageNumber -}} {{- $total := .TotalPages -}} {{/* ALWAYS five numbered pages when there are at least five, centred on the current one and SLID at either end -- so page 1 shows 1-5 and page 215 shows 211-215, rather than trailing off into two buttons. Integer arithmetic throughout, deliberately: math.Min/math.Max return float64, so `eq` against an int is always false and the end-clamp silently never fires. */}} {{- $size := 5 -}} {{- if gt $size $total }}{{ $size = $total }}{{ end -}} {{- $from := sub $cur 2 -}} {{- if lt $from 1 }}{{ $from = 1 }}{{ end -}} {{- $to := add $from (sub $size 1) -}} {{- if gt $to $total -}} {{- $to = $total -}} {{- $from = add (sub $total $size) 1 -}} {{- end -}}

In one flex row they drift sideways as cells come and go and as 1-digit numbers become 3-digit ones -- moving the controls you click repeatedly out from under the cursor. */}}
