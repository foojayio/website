{{- /* One category string -> the name to DISPLAY for it. Takes the raw category as written in `categories:` (or a sponsor's `topics:`). THE TERM PAGE IS THE SINGLE SOURCE OF TRUTH. A chip used to print the raw frontmatter string while the page it links to took its heading from Hugo's title-casing, so the same category read "nosql" on a card and "Nosql" on its own page. Deriving the display name from the term page -- the thing the chip already links to -- means the two cannot disagree. It also makes the acronyms fixable: title-casing produces "Nosql", "Sql" and "JOOQ", and a term with a content file at content/categories//_index.md uses that file's `title:` instead. Three such files exist for exactly that reason. URLS ARE UNAFFECTED: callers build the href from `urlize` of the raw string, and urlize("nosql") == urlize("NoSQL"). Falls back to the raw string when there is no term page, so a `topics:` entry naming a category that does not exist still renders as written. */ -}} {{- $raw := . -}} {{- $name := $raw -}} {{- with site.GetPage (printf "/categories/%s" ($raw | urlize)) -}} {{- $name = .LinkTitle -}} {{- end -}} {{- return $name -}}
