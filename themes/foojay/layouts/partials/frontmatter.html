{{- /* Path to a content file -> its frontmatter as a map, or an empty map. For the two places that read content Hugo deliberately did NOT build: coming-soon.html (future-dated posts) and ad-stats/single.html (expired banners). Nothing else should need it -- a page Hugo DID build exposes .Params. IT STOPS AT THE CLOSING `---`, and that is not tidiness: at least one post has `date:` lines at column 0 in its BODY, so a reader that took the whole file would take a date out of the prose. */ -}} {{- $path := . -}} {{- $fm := dict -}} {{- if fileExists $path -}} {{- $raw := os.ReadFile $path -}} {{- if hasPrefix $raw "---" -}} {{- $block := index (split (strings.TrimPrefix "---" $raw) "\n---") 0 -}} {{- with $block -}} {{- $fm = . | transform.Unmarshal -}} {{- end -}} {{- end -}} {{- end -}} {{- return $fm -}}
