{{- /* Path to a content file (string) in -> its frontmatter as a map out, or an empty map if there is none. This exists for coming-soon.html, which has to read posts Hugo has deliberately not built (see the comment there). Nothing else should need it: a page Hugo DID build exposes its frontmatter as .Params, which is always the right way round. IT STOPS AT THE CLOSING `---`, and that is not defensive tidiness -- content/posts/2025/10/01/jc-ai-newsletter-6/index.md has eleven `date:` lines in its BODY at column 0, so a reader that took the whole file, or one that grepped for a key, would take a date out of the prose. */ -}} {{- $path := . -}} {{- $fm := dict -}} {{- if fileExists $path -}} {{- $raw := os.ReadFile $path -}} {{- if hasPrefix $raw "---" -}} {{- $block := index (split (strings.TrimPrefix "---" $raw) "\n---") 0 -}} {{- with $block -}} {{- $fm = . | transform.Unmarshal -}} {{- end -}} {{- end -}} {{- end -}} {{- return $fm -}}
