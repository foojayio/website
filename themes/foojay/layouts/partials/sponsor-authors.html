{{- /* A sponsor's `authors:` list, normalised to one shape. Takes the sponsor Page; returns a slice of { slug, from, till, dated }, where `from`/`till` are "" when unset and `dated` is true when either is set. WHY THE LIST IS MIXED: an author's posts belong to a sponsor because the author worked there, and people join and leave -- so without dates, articles written for someone else keep appearing. An entry may be: authors: - "tim-kelly" # currently there: nothing to say - slug: "pratik-patel" till: "2026-04-01" # the day they left - slug: "someone-else" from: "2024-06-01" # arrived; earlier posts aren't theirs The bare string stays the default because it is the common case, and a maintainer should not write a two-line map to say "still here". SEMANTICS: a HALF-OPEN range, [from, till). `till` is the first day NOT attributed -- the day they left, which is the date a maintainer knows. That makes the SAME date correct for both sponsors when someone moves, with no gap and no double-attribution, which an inclusive `till` cannot do without an off-by-one. Both keys are optional and independent. Dates go through `time.Format` rather than being compared as written: YAML turns an unquoted 2026-04-01 into a date object and a quoted one into a string, and comparing the two silently fails rather than erroring. ISO strings also make sponsor-posts.html's comparison a plain lexicographic one. One definition, because three things read this list: sponsor-posts.html, and the author list plus the author COUNT on sponsor/section.html. */ -}} {{- $entries := slice -}} {{- range .Params.authors -}} {{- if reflect.IsMap . -}} {{- $from := "" -}} {{- $till := "" -}} {{- with .from }}{{ $from = time.Format "2006-01-02" . }}{{ end -}} {{- with .till }}{{ $till = time.Format "2006-01-02" . }}{{ end -}} {{- $entries = $entries | append (dict "slug" (.slug | default "") "from" $from "till" $till "dated" (or $from $till | not | not)) -}} {{- else -}} {{- $entries = $entries | append (dict "slug" . "from" "" "till" "" "dated" false) -}} {{- end -}} {{- end -}} {{- return $entries -}}
