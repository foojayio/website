{{- /* One tier from the `tiers` list in content/sponsors/_index.md, looked up by name. Takes the tier STRING; returns the whole dict, with `label`, `groupTitle`, `badge` and `noun` always filled in so a caller never writes the fallback itself. A LOOKUP AND NOT `title .`: the listing has each dict in hand, but a sponsor page and a sponsor card know only the string, and `title .` turns "community-partner" into "Community-partner" -- with "Sponsor" hardcoded beside it, which is the one thing a non-paying tier must not be called. An UNKNOWN tier still gets a sensible dict: a tier renamed upstream must degrade to an odd label, never a blank badge or a build error. */ -}} {{- $slug := . -}} {{- $label := replace (replace $slug "-" " ") "_" " " | title -}} {{- $tier := dict "name" $slug "label" $label -}} {{- with site.GetPage "/sponsors" -}} {{- range .Params.tiers -}} {{- if eq .name $slug -}}{{- $tier = . -}}{{- end -}} {{- end -}} {{- end -}} {{- $label = $tier.label | default $label -}} {{- return merge $tier (dict "label" $label "groupTitle" ($tier.groupTitle | default (printf "%s Sponsors" $label)) "badge" ($tier.badge | default (printf "%s Sponsor" $label)) "noun" ($tier.noun | default "sponsor")) -}}
