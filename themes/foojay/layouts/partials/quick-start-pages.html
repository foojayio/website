{{- /* THE SINGLE DEFINITION OF "THE PAGES UNDER A QUICK START HUB". Takes a hub page (`/java-quick-start/`, `.../install-java/`, `.../quick-start-tutorial/`); returns its children in reading order. Three places ask this and must not answer differently: the home page band, the list a hub page renders itself ({{< quick-start-steps >}}), and the series partials on a step. Before this the lists were hand-typed in Markdown as well -- 38 absolute foojay.io links whose titles had already drifted from the pages they opened. The children of a folder, found by `File.Dir` on site.RegularPages the way series-steps.html finds a series: none of these folders has an `_index.md`, so no hub page is a Hugo parent of its own children. The folder is built from the hub's own `File.ContentBaseName`, so renaming a hub renames the query. */ -}} {{- $hub := . -}} {{- $pages := slice -}} {{- if and $hub $hub.File -}} {{- $kids := where site.RegularPages "File.Dir" (printf "%s%s/" $hub.File.Dir $hub.File.ContentBaseName) -}} {{- /* WEIGHT IF THE AUTHOR STATED ONE FOR EVERY CHILD, ALPHABETICAL OTHERWISE. A weight is this site's way of saying "these pages are a sequence", and the tutorial steps carry one each. The install guides deliberately do not -- they are alternatives, not a path -- so there is nothing to sort by but the title, which happens to be the useful order here. All-or-nothing rather than "weighted ones first": a folder where only some pages carry a weight is a mistake to notice, not an order to honour. */ -}} {{- $weighted := where $kids "Weight" ">" 0 -}} {{- if and $kids (eq (len $weighted) (len $kids)) -}} {{- $pages = sort $kids "Weight" -}} {{- else -}} {{- $pages = sort $kids "Title" -}} {{- end -}} {{- end -}} {{- return $pages -}}
