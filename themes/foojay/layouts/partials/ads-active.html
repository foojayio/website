{{- /* The banners currently running, in order. THE single definition of what "an ad" is on this site -- the home page carousel and the sidebar slot both come from here, so the two can never disagree about which campaigns are live. Takes no arguments, returns a slice of pages (empty when nothing is running, which every caller must treat as "render nothing" -- an empty carousel is worse than no carousel). WHAT IS RUNNING IS HUGO'S OWN ANSWER, NOT OURS: a banner carries publishDate/expiryDate and Hugo drops a page outside that window from the build entirely, so there is no date comparison here or in the templates, and nothing to switch off when a campaign ends. Contrast upcoming-events.html, which DOES compare dates -- an event stays on the calendar as a thing that happened, a finished banner is simply gone. THE ORDER IS .Pages' OWN (weight, then title), which is why there is no sort: an editorial `weight:` floats a banner to the front, and with none set the order is alphabetical and stable across builds. That matters -- the first slide is the one most readers see, so it must not depend on directory-read order. partialCached at every call site: it depends on the content, not the page, and the sidebar alone would re-resolve it on 4000 pages. */ -}} {{- $ads := slice -}} {{- with site.GetPage "/ads" -}} {{- $ads = .Pages -}} {{- end -}} {{- return $ads -}}
