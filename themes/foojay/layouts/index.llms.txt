{{- /*
  /llms.txt -- the llmstxt.org convention: a short, markdown-formatted map of
  the site, written for a model that has a context window rather than a crawl
  budget. Wired up as the LLMS output format on the home page (see hugo.toml);
  the sibling to robots.txt, which says what a machine MAY fetch while this says
  what is WORTH fetching.

  It is a CURATED index, not a dump. The convention is that the file fits in a
  context window, so listing all 2153 posts would defeat it -- and would only
  restate sitemap.xml, which already carries every URL with a lastmod. Hence the
  "Complete indexes" block first: anything not named below is one link away, and
  a model that needs everything is told exactly where everything is.

  EVERYTHING HERE IS DERIVED, so there is no second list to keep in step with
  the site:

    - the navigation sections are the [[menu.footer]] columns, which CLAUDE.md
      already makes the single definition of the site's own navigation. Adding a
      page to the footer adds it here, with nothing to remember.
    - the Quick Start steps come from partials/series-steps.html, so they cannot
      fall out of order with the progress bar on the pages themselves.
    - the glossary is content/pedia/, the topics are the categories taxonomy,
      and the recent articles are the posts section by date.
    - every description is partials/meta-description.html, the same string the
      page's own <meta name="description"> carries -- so this file cannot
      describe a page differently from the page.

  Two things are deliberate:

  URLs are ABSOLUTE (.Permalink / absURL). This is the "absolute by contract"
  exception in CLAUDE.md's relative-links rule and the clearest case of it: the
  file is read off-site by something that has no notion of our origin, so a
  root-relative path here resolves against whatever host is asking.

  It self-flips at cutover like robots.txt and baseof.html's noindex, off the
  same baseURL != productionBaseURL test. The trial deploy is a byte-for-byte
  copy of the live WordPress site, so publishing a curated index of it would be
  inviting a model to ingest the duplicate rather than foojay.io -- the exact
  thing the trial's `Disallow: /` exists to prevent. Nothing to unset on the day.
*/ -}}
