{{- /* Link render hook. Four jobs: 1. An absolute foojay.io link -> this site's own path. 2. A root-relative internal link -> plus the baseURL subpath (relURL only prefixes it when the path does not already start with "/"). 3. A link to any other host -> opens in a new tab. 4. A bare filename matching a page-bundle resource -> that resource. String checks, not urls.Parse, which errors on malformed URLs. htmlUnescape on .Destination/.Title is what goldmark's own renderer does, and taking over rendering means taking that over too. CommonMark decodes entity references in destinations, so an href holding `?a=1&b=2` is CORRECT Markdown for `?a=1&b=2`; without this the raw `&` is escaped a second time and the browser requests a param named `amp;b`. Same failure mode as render-codeblock.html. */ -}} {{- $orig := .Destination | htmlUnescape -}} {{- $dest := $orig -}} {{- $isAbs := or (hasPrefix $orig "http://") (hasPrefix $orig "https://") (hasPrefix $orig "//") -}} {{- /* Host-anchored so foojay.social and query strings don't false-match. */ -}} {{- $internal := or (hasPrefix $orig "https://foojay.io") (hasPrefix $orig "http://foojay.io") (hasPrefix $orig "https://www.foojay.io") (hasPrefix $orig "http://www.foojay.io") (hasPrefix $orig "//foojay.io") -}} {{- $external := and $isAbs (not $internal) -}} {{- if $internal -}} {{- $dest = replaceRE "^(https?:)?//(www\\.)?foojay\\.io" "" $dest -}} {{- end -}} {{- if not (or $external (hasPrefix $dest "http") (hasPrefix $dest "//") (hasPrefix $dest "mailto:") (hasPrefix $dest "#") (hasPrefix $dest "data:")) -}} {{- /* 4. A bare filename co-located with index.md -> that page-bundle resource, the same lookup render-image.html does. Without it a link to a file in the post's own folder resolves against the SITE ROOT while Hugo publishes the file inside the bundle, so the link 404s silently. An image already worked, which is why it went unnoticed. Only a destination that actually matches a resource is rewritten; everything else falls through to the relURL branch. */ -}} {{- $res := false -}} {{- with .Page }}{{ $res = .Resources.GetMatch $dest }}{{ end -}} {{- with $res -}} {{- $dest = .RelPermalink -}} {{- else -}} {{- $dest = $dest | strings.TrimPrefix "/" | relURL -}} {{- end -}} {{- end -}} {{ .Text | safeHTML }} {{- /* NO TRAILING NEWLINE, and the `{{-` above is the only thing removing it. A link is INLINE, so a newline after lands between the link and what follows and HTML collapses it to a space -- every link followed by punctuation renders as "the Java Version Almanac .". An editor that re-adds a final newline brings the space back; the chomp makes that harmless. */ -}}
