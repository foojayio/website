{{- /* Image gallery -- a responsive grid of co-located images. USAGE -- one image per line, filename first: {{< gallery >}} one.png two.png | An optional caption {{< /gallery >}} A `|` separates the filename from its caption, and a second `|` adds alt text when it should differ from the caption (rare -- the caption is used as the alt text otherwise). Because each image is on its own line there is nothing to quote or escape: commas, quotes and colons in a caption are all just text. Optional attributes on the opening tag: {{< gallery cols="2" caption="One caption for the whole gallery" >}} cols is a MAXIMUM, not a fixed count: the grid uses auto-fit, so images reflow to fewer columns on a narrow screen, and a gallery never opens more columns than it has images. Default 3. There is also a one-line form for the simple case. Note the closing `/` -- this template reads .Inner, so Hugo requires every call to be either closed (above) or self-closed (here): {{< gallery "one.png" "two.png" />}} Filenames resolve through resource-url.html, so a bare name means "the file sitting next to index.md in this post's folder" -- the same rule as a plain Markdown image. Full URLs and /static paths work too. Images are click-to-enlarge for free -- static/js/lightbox.js binds every `.prose img`, so no per-image markup is needed here. Where a filename carries WordPress's `-1024x768` size suffix and the full-size original sits in the same bundle, the image is wrapped in a link to that original so the lightbox opens the full-size version instead of the thumbnail -- derived rather than asked for, which is what the migrated WordPress galleries used to spell out as markup. */ -}} {{- /* Items: positional args on a self-closed call, otherwise one per line. */ -}} {{- $items := slice -}} {{- if and (not .IsNamedParams) .Params -}} {{- range .Params }}{{ with trim . " " }}{{ $items = $items | append . }}{{ end }}{{ end -}} {{- else -}} {{- range split .Inner "\n" }}{{ with trim . " \t\r" }}{{ $items = $items | append . }}{{ end }}{{ end -}} {{- end -}} {{- $cols := int (.Get "cols" | default 3) -}} {{- if or (lt $cols 1) (gt $cols 6) }}{{ $cols = 3 }}{{ end -}} {{- /* Never open more columns than there are images, or a two-image gallery renders two thirds of a row wide and a third of one empty. */ -}} {{- if and $items (lt (len $items) $cols) }}{{ $cols = len $items }}{{ end -}} {{- if $items -}} {{- else -}} {{- errorf "gallery shortcode in %q: no images given. Put one filename per line between {{< gallery >}} and {{< /gallery >}}" $.Page.File.Path -}} {{- end -}}
