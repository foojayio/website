# Social icons

Eight outline SVGs from [Tabler Icons](https://github.com/tabler/tabler-icons), commit `0239805680a36bab4e1070529b6744924402d804`, under the included MIT license. Only these local assets are shipped; no icon library or network request is added to the site.

`partials/icon.html` renders them decoratively inside a named link. The shared `icon-button` class also styles header controls.
